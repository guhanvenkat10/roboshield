# public/

Drop demo assets here:

- **`demo.mp4`** — your recorded robot demo clip. It auto-plays in the pitch deck's
  demo slide (`/present`). Until it exists, the slide shows a labeled placeholder.
- **`demo-poster.jpg`** (optional) — a still frame shown before the video plays.

Keep `demo.mp4` reasonably sized (1080p, a few MB) so the deck loads instantly.
